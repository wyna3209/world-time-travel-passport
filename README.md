# 시간 여행 여권

이 폴더는 GitHub Pages용 정적 사이트입니다. 첫 화면은 매번 새 값으로 생성되는 시계 연습 문제입니다. 20문제를 모두 풀면 결과 화면이 나오며, 15문제 이상 맞히면 세계 여행을 시작하고 그보다 적으면 새 문제로 다시 도전할 수 있습니다.

## 배포

GitHub Pages는 GitHub Actions로 자동 배포됩니다. `main` 브랜치에 푸시하거나 Actions 탭에서 **Deploy static site to GitHub Pages**를 수동 실행하면 됩니다.
