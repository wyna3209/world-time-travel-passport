# 시간 여행 여권

이 폴더는 GitHub Pages용 정적 사이트입니다. 첫 화면은 매번 새 값으로 생성되는 시계 연습 문제입니다. 기존 네 가지 유형을 5문제씩 총 20문제 출제합니다. 20문제를 모두 풀면 결과 화면이 나오며, 15문제 이상 맞히면 2초 뒤 세계 여행(`world_time_travel (2).html`)으로 자동 이동합니다. 그보다 적으면 새 문제로 다시 도전할 수 있습니다. 각 문제는 가장 최근에 확인한 답으로 채점합니다.

## 배포

GitHub Pages는 GitHub Actions로 자동 배포됩니다. `main` 브랜치에 푸시하거나 Actions 탭에서 **Deploy static site to GitHub Pages**를 수동 실행하면 됩니다.
